This repository contains the complete UI/UX design for a Digital Library & Research Hub mobile application, created as part of UI UX LAB ASSIGNMENT 07 for the UIUX-D course.

🧩 Problem Statement

Students often struggle to find reliable academic resources, research papers, and e-books in one centralized platform.

This project aims to design a Digital Library & Research Hub that provides students with easy, organized, and efficient access to academic resources along with research and citation support 

UIUX_LAB_ASSIGNMENT


🎯 Objective

Centralize academic resources for students

Simplify searching and filtering of research material

Improve reading, saving, and citation management experience

Design a clean, modern, and intuitive mobile interface

⭐ Key Features

🔍 Smart Search with filters (topic, author, year)

📌 Bookmarking & Reading List

📑 Citation Generator & Reference Manager

🎓 Integration with Google Scholar & University Libraries

🛠 Tools Used

Figma – UI design & prototyping

UI Design Principles – Hierarchy, consistency, accessibility

📱 Screen Flow & Design Overview
1️⃣ Loading Screen

App branding with a minimal, elegant introduction

Establishes identity of the All-Access Library Hub

2️⃣ Login Screen

Simple authentication interface

Options to Sign In or Create Account

3️⃣ Home Page (Version 1)

Personalized greeting

Search bar for quick access

Recommended book based on last read

Bottom navigation for easy access

4️⃣ Home Page (Version 2)

Category-based browsing

Trending books section

Top authors showcase

5️⃣ Resource Details Screen

Detailed book/resource view

Description, author information

Options to save or view details

6️⃣ Saved Books (My Book Shelf)

Displays saved books

Reading progress indicator

Organized reading management

7️⃣ Citation Generator

APA citation format

Fields for author, year, title, and publisher

Supports academic referencing needs

🧠 Design Approach

User-centric design focusing on students

Minimalistic dark theme for reduced eye strain

Clear navigation and visual hierarchy

Academic-focused aesthetics and usability
